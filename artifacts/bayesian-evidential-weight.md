## 5. Falsifiable Predictions (SALVAGE PATH)

The paper's predictions-scorecard (`artifacts/predictions-scorecard.md`) contains genuine falsifiable predictions for individual pillars. These CAN carry evidential weight if:

- **Pre-registration:** Each prediction must be timestamp-stamped BEFORE data collection. The predictions scorecard (2026-07-27+) is timestamped; data collection status should be verified.
- **Falsifiability:** Each prediction has a threshold — these ARE concrete disconfirmation conditions. ✓
- **Surprise accounting:** For each prediction, compute P(observation | null model). If the null model is "Standard Model / standard crypto / standard ontology," this is computable.

**Recommended restructure:** Rather than claiming "the convergence is the evidence," the paper should claim: "Here are N falsifiable predictions, pre-registered on [date]. If confirmed, each carries positive Δlog-odds." The CONVERGENCE itself is a narrative framing, not evidence.
